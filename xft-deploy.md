# XFT deploy notes

## Build

Set `STATIC_BASE_URL` to the jsDelivr path of this repository, then build:

```bash
cd product
STATIC_BASE_URL=https://cdn.jsdelivr.net/gh/a18361272323/xft-lottery@main/product/dist npm run build
```

On Windows PowerShell:

```powershell
cd product
$env:STATIC_BASE_URL = "https://cdn.jsdelivr.net/gh/a18361272323/xft-lottery@main/product/dist"
npm run build
```

Build outputs:

- `product/dist/index.html`: standalone test page
- `product/dist/index.srcdoc.html`: XFT iframe `srcdoc` page

## XFT Page onMount

Paste the base64 content of `product/dist/index.srcdoc.html` into `base64Decode`.

```js
var currentWindow = env.getCurrentWindow();
var screenWidth = currentWindow.screen.width;
var screenHeight = currentWindow.screen.height;

var container = document.getElementsByClassName("xcode-pc-page")[0];
container.setAttribute(
  "style",
  "width: " + screenWidth + "px; height: " + screenHeight + "px;"
);
container.style.padding = "0px 0px";

var iframe = document.createElement("iframe");
iframe.setAttribute("id", "lottery-frame");
iframe.frameBorder = "0";
iframe.setAttribute("allow", "fullscreen");
iframe.setAttribute("allowfullscreen", "true");
iframe.setAttribute("webkitallowfullscreen", "true");
iframe.setAttribute(
  "style",
  "width: 100%; height: 100%; position: relative;"
);

var htmlContent = base64Decode("PASTE_BASE64_SRCDOC_HERE");
iframe.srcdoc = htmlContent;
container.appendChild(iframe);
```

## Required model data

- `lottery_config`: add `key_name = company`, `key_value = your company name`
- `lottery_prize`: configure prizes with `sort_no` in the original prize order
- `lottery_user`: import user rows
- `lottery_result`: generated by the lottery page
